Telegram Marketing & Live Chat

Promotions, announcements and instant customer chat - straight from Odoo

  • Campaigns: broadcast promotions and announcements to all subscribers, tagged chats, a custom filter or a hand-picked list. Personalize with placeholders, attach an image or a file, add link buttons, schedule for later and follow sent / failed statistics.
  • Inbox: every private chat, group and channel in one place, with a live conversation view and an instant reply box - any chat, any message.
  • Automatic messages: welcome on /start, unsubscribe on /stop, keyword auto-replies in any language (Khmer, English...) and an optional default reply.
  • Customers: subscribers become contacts automatically; send a Telegram message from any contact.
  • Webhook or polling: instant delivery with a public HTTPS URL, or polling every minute when there is none.
