Infobip SMS Connector

Send every SMS from Odoo through your own Infobip account — ideal for Cambodia (+855) and international routes where you want your own sender ID, routes and pricing instead of Odoo IAP credits.

Works everywhere Odoo sends SMS

  • CRM: text leads and customers from the chatter, SMS activities
  • SMS Marketing (mass_mailing_sms): mass campaigns with per-recipient tracking
  • Contacts / Sales / Deliveries and any automation or server action using SMS templates

Features

  • Official Infobip HTTP API (POST /sms/2/text/advanced), batched — up to 500 SMS per call
  • Delivery reports pushed back to Odoo: messages show as Delivered, Sent or Failed with the operator reason
  • Custom alphanumeric sender ID (register your brand for Smart, Cellcard, Metfone, ...)
  • Cambodian local numbers (012 345 678) automatically get the +855 prefix (configurable)
  • Send Test SMS wizard right in the settings
  • Disable it any time to fall back to the standard Odoo IAP SMS service

Setup in 2 minutes

  1. Create an account on portal.infobip.com and copy your API key and base URL
  2. In Odoo: Settings > Infobip SMS — enable, paste both values, set your sender ID, save
  3. Click Send Test SMS and check your phone 📱
