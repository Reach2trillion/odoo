📱 Send by Telegram

Send quotations, orders, and files directly to your customers via Telegram!

⚡ Why Choose This Module?

In today's fast-paced business world, email isn't always the quickest way to reach your customers. With Send by Telegram, you can send quotations, purchase orders, and documents instantly to Telegram groups where your customers are already active. No more waiting for email replies!

✨ Key Features

📄 PDF Documents

Automatically generate and send PDF quotations and purchase orders with a single click. Professional documents delivered instantly.

🖼️ Image Preview

Send images with full preview - not as file attachments. Your customers see images immediately in the chat.

👥 Group Messaging

Send messages to Telegram groups. Perfect for B2B communication with dedicated client groups.

💬 Chatter Integration

Send messages directly from Odoo's chatter. Attach any files and they appear in the message history.

🌐 Multilingual

Full support for Uzbek, Russian, and English languages. Messages automatically adapt to the user's language preference.

🔄 Status Updates

Quotation status automatically changes to "Sent" when your message is delivered via Telegram.

🚀 How It Works

  1. Create Bot: Create a Telegram bot via @BotFather (free!)
  2. Configure Token: Add your bot token in Settings → General Settings → Send by Telegram
  3. Test Connection: Click "Test Bot" to verify everything works
  4. Add Group IDs: Configure Telegram Group ID for each customer/vendor in Contacts
  5. Start Sending: Click "Send by Telegram" on any quotation or purchase order!

📋 Requirements

  • Odoo 18.0
  • Telegram Bot (create free via @BotFather)
  • Bot must be added as admin to target groups
  • Python requests library (usually pre-installed)

  • B2B Sales: Send quotations directly to client's Telegram group for faster response
  • Procurement: Share purchase orders with vendors instantly
  • Customer Support: Send documents and images from chatter during support conversations
  • Field Sales: Sales team can send quotes on-the-go from mobile Odoo
