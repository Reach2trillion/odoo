Telegram Notifications

Automatically message your customers on Telegram (requires the Telegram Login module):

  • 📄 Quotation sent — with amount and portal link
  • ✅ Order confirmed
  • 📦 Delivery shipped — with carrier tracking reference and link
  • 🧾 Invoice posted

Each event can be toggled in Settings. The customer's Telegram username is shown on the contact form for manual follow-up.
