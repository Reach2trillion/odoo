# Odoo Custom Addons — Cambodia

Custom Odoo 18 addons for Cambodian localization.

| Module | Description |
|---|---|
| `addons/l10n_kh_tax` | Cambodia accounting & tax: GDT monthly tax declaration, VAT / WHT / PToI, e-Filing export, audit workflow |

Add the `addons/` directory to your Odoo `addons_path` and install the
modules from the Apps menu.
