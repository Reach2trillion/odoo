Telegram Login

Adds a "Log in with Telegram" button to the Odoo login page. Users whose account is linked to a Telegram account sign in with one tap; unknown Telegram accounts can get a (portal) user created automatically when Free sign up is enabled. TOTP two-factor authentication still applies.

Login methods

Choose one in Settings → General Settings → Telegram Authentication → Login Method:

  • Telegram chat (recommended): the customer taps the button, Telegram opens on your bot right away, they tap Start and then Yes, Login, and the login page signs them in. With the optional One-time code, the bot then sends a code that they type on the website. No OAuth screens; the bot can then message the customer and ask for their phone number with one tap.
  • OpenID Connect: Telegram's authorization page (authorization code flow with PKCE).
  • Legacy Login Widget: the old widget, deprecated by Telegram; only for bots that were never switched to OpenID Connect (needs /setdomain in @BotFather).

Security

  • Chat login requests are short-lived (10 minutes), bound to the browser that started them, confirmed only by the Telegram account that opened the link, and completed exactly once. The prompt shows the requesting device and IP address.
  • The Login Successful message has an Open website button that opens the site already signed in, also in Telegram's own browser: a single-use secret valid 10 minutes, kept in the URL fragment so it never reaches server logs.
  • One-time code: the code is shown in Telegram only after the customer taps Yes and must be typed on the website where the login was started, so somebody who sends a customer their own login link cannot get in without the customer handing the code over (the bot warns them never to).
  • Self-service linking at /auth/telegram/link: users with a password re-enter it first, accounts without one log in with their current Telegram again (an account with neither sets a password first); the previously linked Telegram account is notified when it is replaced or unlinked; an account that can only sign in with Telegram cannot be unlinked.
  • Single-use, hashed login tokens; the bot token is never written to the logs.

Setup (Telegram chat login)

  1. Create a bot with @BotFather (/newbot) and note its username and token.
  2. Make sure web.base.url is your public https:// address (Settings → Technical → System Parameters). Telegram calls https://yourdomain/auth/telegram/webhook. Behind a reverse proxy run Odoo with proxy_mode = True (forward X-Forwarded-For / -Proto / -Host) and set web.base.url.freeze to True.
  3. Settings → General Settings → Telegram Authentication: choose Telegram chat, enter the bot username and token, save. The webhook is registered automatically; the Status line shows the result (use Register Webhook / Check Status if needed). The login button only appears once the webhook is registered.
  4. Optional: enable One-time code, Ask for phone number after login and Free sign up.

Setup (OpenID Connect)

  1. In @BotFather open your bot's Web Login settings and Switch to OpenID Connect Login (this permanently disables the legacy widget for the bot). Register the redirect URI https://yourdomain/auth/telegram/callback and your domain as trusted origin, then copy the Client ID and Client Secret.
  2. In Odoo choose OpenID Connect and paste the Client ID and Client Secret (keep the bot username and token filled in for notifications and the chat login).
