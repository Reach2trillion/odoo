Telegram Login

Let users sign in and sign up with their Telegram account, using the official Telegram Login Widget.

  • One-click login for users linked to a Telegram account
  • Automatic portal user creation when free sign up is enabled
  • Self-service account linking at /auth/telegram/link
  • Cryptographic verification of every Telegram payload (HMAC-SHA256)
  • Single-use, short-lived, hashed login tokens; TOTP 2FA still applies

Setup

  1. Create a bot with @BotFather and note its username and token
  2. Send /setdomain to @BotFather with your Odoo domain (HTTPS required)
  3. Enter both values in Settings → General Settings → Telegram Authentication
